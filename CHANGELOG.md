# История изменений

## 1.0.0.2

- Описание проекта записано русскими ключами: с английскими среда разработки при подключении
  библиотеки не находила поставщика («Поставщик должен быть указан»).
- Сборка выпускается в формате `.xlib`, как её выгружает панель управления.
- Представление библиотеки — «Внутренний чат».

## 1.0.0.1

Первая публичная версия.

- Беседы, собеседники, сообщения с форматированием, эмодзи, файлами, ответами и реакциями.
- Окно беседы — веб-виджет поверх HTTP-сервиса: своё сообщение сразу, чужие изменения —
  за несколько секунд без перезагрузки; одинаково в браузере и в мобильном клиенте.
- Состояния участника: «Администратор», «Может писать», «Только читает».
- Служебные сообщения, удаление администратором с отметкой, шапка окна, список участников
  с признаком «в сети», непрочитанное и сводки.
