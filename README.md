# ВебЧат — библиотека переписки для 1С:Предприятие.Элемент

Переписка в беседах для приложений на 1С:Предприятие.Элемент: окно беседы — веб-виджет
поверх HTTP-сервиса библиотеки, одинаковый в браузере и в мобильном клиенте Элемента.

Библиотека выросла из социальной сети для профессионалов [«Профессионалы»](http://allhands.pro)
и работает там в чатах профессиональных областей, пар коллег и команд.

## Что умеет

- сообщения с жирным и курсивом, эмодзи, файлами и изображениями, ответ с цитатой,
  правка и удаление своего, реакции «Ошибка», «Идея», «Нравится»;
- своё сообщение появляется сразу, чужие новые, правки, удаления и реакции — за несколько
  секунд, без перезагрузки; порции по 20 сообщений, «Загрузить предыдущие», плашка
  «Новые сообщения»;
- шапка окна с названием и аватаром беседы, список участников с признаком «в сети»;
- состояния участника: **Администратор** (читает, пишет, удаляет чужие сообщения
  с отметкой «Удалено администратором»), **Может писать**, **Только читает**;
- служебные сообщения о событиях (без автора, непрочитанными не считаются);
- непрочитанное по беседам и всего, сводки для писем;
- потеря связи не теряет набранное: «Нет связи, повторяем…», после восстановления —
  догрузка пропущенного.

## Главный принцип

**Библиотека не знает ваших пользователей, групп и правил и не вычисляет прав.** Кто с кем
состоит в беседе и что ему можно, решает приложение-потребитель: оно регистрирует своих
участников собеседниками, отражает беседы и их состав и передаёт каждому состояние.
Подробно — [порядок встраивания](docs/встраивание.md).

## Скачать

Сборка для загрузки — zip-архив проекта на странице
[Releases](../../releases): `webchat-<версия>.zip`. В панели управления: **Проекты → + Добавить
проект → Загрузить проект из файла**, затем подключить библиотеку к своему проекту
(**Описание проекта → Библиотеки**).

## Выпуск версии

Версия — в `ВебЧат/Проект.yaml` (`Version`). Новая версия в `main` запускает процесс
«Выпуск»: он ставит метку `v<версия>`, собирает zip-архив проекта и публикует его на странице
Releases. Версия, у которой выпуск уже есть, пропускается.
