# Программный интерфейс

Общий модуль `ВебЧат`, все методы — `@Глобально`, на сервере.

## Собеседники

| Метод | Что делает |
|---|---|
| `ТекущийСобеседник(): Собеседники.Ссылка?` | собеседник текущего сеанса — через контракт `СеансВебЧата` |
| `ОбновитьСобеседника(Ид: Ууид, Наименование: Строка, Аватар: ДвоичныйОбъект.Ссылка?): Собеседники.Ссылка` | завести или обновить собеседника с заданным идентификатором |
| `ОтключитьУчастника(Собеседник: Собеседники.Ссылка, Отключить: Булево)` | скрыть или вернуть его сообщения и реакции; отключённому ключ не выдаётся |
| `УдалитьУчастника(Собеседник: Собеседники.Ссылка)` | удалить его сообщения с файлами и реакции, участие в беседах, его самого |
| `СоставМатериалов(Собеседник): МатериалыСобеседника` | сколько у него сообщений, файлов, реакций, бесед — для предупреждения перед удалением |
| `ОтметитьПрисутствие(Собеседник: Собеседники.Ссылка)` | отметка «в сети» |

## Беседы и состав

| Метод | Что делает |
|---|---|
| `ОтразитьБеседу(Ид: Ууид, Наименование: Строка, Аватар: ДвоичныйОбъект.Ссылка?): Беседы.Ссылка` | завести беседу с заданным идентификатором или обновить название и аватар |
| `ОтразитьУчастника(Беседа, Собеседник, Состояние: СостоянияУчастникаБеседы?)` | внести, сменить состояние или (`Неопределено`) убрать из беседы |
| `Состояние(Беседа, Собеседник): СостоянияУчастникаБеседы?` | состояние собеседника в беседе |
| `ДобавитьСобытие(Беседа, Текст: Строка)` | служебное сообщение без автора |
| `УдалитьБеседу(Беседа)` | удалить беседу с перепиской |

## Списки, счётчики, сводки

| Метод | Что возвращает |
|---|---|
| `СписокБесед(): Массив<СтрокаСпискаБесед>` | все беседы: `Беседа`, `Наименование`, `Аватар` |
| `НепрочитанныхВсего(Собеседник): Число` | всего непрочитанных |
| `НепрочитанныхПоБеседам(Собеседник): Соответствие<Беседы.Ссылка, Число>` | непрочитанные по беседам |
| `Сводка(Собеседник, С: ДатаВремя, По: ДатаВремя): Массив<СводкаБеседы>` | за период по беседам: `Новых`, `СРеакциями`, `СОтветами` — для писем |
| `СообщенийПоБеседам(Беседы: ЧитаемыйМассив<Беседы.Ссылка>): Соответствие<Беседы.Ссылка, Число>` | число сообщений |
| `ЕстьСообщения(Беседа): Булево` | есть ли в беседе сообщения |

Непрочитанными не считаются свои сообщения, служебные, сообщения отключённых и беседы,
где собеседник — администратор.

## Перечисление `СостоянияУчастникаБеседы`

`Администратор`, `МожетПисать`, `ТолькоЧитает`.

## Контракт `СеансВебЧата`

Одиночный, обязательный, на сервере: `ТекущийСобеседник(): Собеседники.Ссылка?`.
