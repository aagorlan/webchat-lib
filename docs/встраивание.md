# Порядок встраивания

Пространство имён библиотеки — `DP::ВебЧат::Основное`. Во всех примерах ниже
`Участники` — справочник участников вашего приложения; подставьте свой.

## 1. Загрузить и подключить

1. Скачать `webchat-<версия>.xlib` со страницы Releases.
2. Панель управления → **Проекты → + Добавить проект → Загрузить проект из файла** → выбрать
   сборку → **Добавить**. Библиотека появится в списке проектов как «Внутренний чат».
3. В своём проекте: **Описание проекта → Библиотеки → Добавить элемент** → «Внутренний чат» (`ВебЧат`).
   В `Проект.yaml` появится:

   ```yaml
   Библиотеки:
       -
           Имя: ВебЧат
           Поставщик: DP
           Версия: 1.0.0.1
   ```

4. В подсистемах, которые работают с чатом, — `Использование` в `Подсистема.yaml`
   и `Импорт:` у элементов: `DP::ВебЧат::Основное`; в модулях —
   `импорт DP::ВебЧат::Основное`.

## 2. Сказать библиотеке, кто работает: контракт `СеансВебЧата`

Контракт одиночный и обязательный: без реализации окно беседы не откроется. Реализация —
общий модуль на сервере:

```yaml
ВидЭлемента: ОбщийМодуль
Ид: <новый UUID>
Имя: СеансЧата
ОбластьВидимости: ВПодсистеме
Импорт:
    - DP::ВебЧат::Основное
НастройкиТипа:
    Контракты:
        - СеансВебЧата
Окружение: Сервер
```

```xbsl
импорт DP::ВебЧат::Основное

@Глобально
@Реализация
метод ТекущийСобеседник(): Собеседники.Ссылка?
    знч Участник = ТекущийУчастник()   // ваш способ узнать участника сеанса
    возврат Участник == Неопределено ? Неопределено : новый Собеседники.Ссылка(Участник!.Ид)
;
```

Собеседник — копия вашего участника в библиотеке **с тем же идентификатором**: так ссылку
на собеседника всегда можно получить из участника и обратно.

## 3. Регистрировать участников собеседниками

При каждой записи участника передать библиотеке имя и аватар — подпиской на запись:

```xbsl
@НаСервере
@Подписка(Событие{Участники.Объект.ПослеЗаписи})
метод ПослеЗаписиУчастника(Источник: Участники.Данные, До: Участники.Данные, Параметры: Участники.ПараметрыЗаписи)
    исп КонтекстДоступа.Привилегированный()
    ВебЧат.ОбновитьСобеседника(Источник.Ссылка.Ид, Источник.Наименование, Источник.Аватар)
;
```

- Отключить участника (его сообщения и реакции скрываются у всех) —
  `ВебЧат.ОтключитьУчастника(Собеседник, Истина)`, вернуть — с `Ложь`.
- Удалить окончательно (сообщения пропадают с файлами, в ответах на них — «Сообщение
  удалено») — `ВебЧат.УдалитьУчастника(Собеседник)`.
- Уже существующих участников зарегистрировать один раз своей обработкой.

## 4. Отражать беседы и состав

Беседа — отражение вашей группы (команды, чата раздела, обращения…). Удобно давать
беседе **идентификатор объекта группы**:

```xbsl
знч Беседа = ВебЧат.ОтразитьБеседу(Команда.Ид, Команда.Наименование, Команда.Аватар)
ВебЧат.ОтразитьУчастника(Беседа, новый Собеседники.Ссылка(Участник.Ид), СостоянияУчастникаБеседы.МожетПисать)
```

| Состояние | Что может участник |
|---|---|
| `Администратор` | читает, пишет, отвечает, удаляет чужие сообщения — они остаются с отметкой «Удалено администратором»; реакций не ставит; в списке участников не виден |
| `МожетПисать` | читает, пишет, отвечает, правит и удаляет свои, ставит реакции |
| `ТолькоЧитает` | читает |
| `Неопределено` | убрать из беседы: беседу он больше не видит |

Вызывать после каждого изменения группы — `ОтразитьБеседу` и `ОтразитьУчастника` ничего
не делают, если ничего не поменялось. Событие в группе — служебным сообщением:
`ВебЧат.ДобавитьСобытие(Беседа, "Иван Петров вернулся в чат")`. Группа удалена —
`ВебЧат.УдалитьБеседу(Беседа)`.

## 5. Показать окно беседы

Компонент `ОкноБеседы` — в своей форме:

```yaml
-
    Тип: ОкноБеседы
    Имя: ОкноБеседы
    Беседа: =Беседа
    Версия: =Версия
```

| Свойство | Зачем |
|---|---|
| `Беседа` | открытая беседа; сменили — окно открывает другую |
| `Версия` | увеличьте после смены состояния участника — окно перечитает беседу с новыми правами |
| `ЗаголовокБеседы` | своё название в шапке окна (необязательно; по умолчанию — название беседы) |
| `СобеседникНаАватаре` | чей аватар в шапке (необязательно; по умолчанию — аватар беседы) — например, собеседника в личной беседе двоих |

Список бесед строит приложение: `ВебЧат.СписокБесед()` (все беседы),
`ВебЧат.НепрочитанныхПоБеседам(Собеседник)` и `ВебЧат.НепрочитанныхВсего(Собеседник)` —
счётчики. Таблицы библиотеки пользователям не видны: читайте их только через эти методы.

## 6. Отмечать присутствие

«В сети» в списке участников — по отметке присутствия. Ставьте её из таймера,
который работает, пока приложение открыто (например, обновления меню раз в 10 секунд),
в серверном методе:

```xbsl
ВебЧат.ОтметитьПрисутствие(новый Собеседники.Ссылка(Участник.Ид))
```

В базу отметка пишется не чаще раза в 15 секунд; «в сети» — отметка не старше 30 секунд.

## 7. Проверить

- Окно беседы показывает «Доступ к чату закрыт» — у собеседника нет записи в беседе
  или он отключён: проверьте `ОтразитьУчастника`.
- Окно пустое — контракт `СеансВебЧата` вернул `Неопределено`.
- Ошибки сервиса пишутся в журнал событий событием `ОшибкаВебЧата`.
