# HTTP-сервис и виджет

## Как устроено окно беседы

`ОкноБеседы` выдаёт ключ доступа и кладёт в `КонтейнерHtml` страницу виджета с параметрами
беседы. Дальше виджет сам ходит к HTTP-сервису библиотеки: грузит порцию сообщений,
раз в 3 секунды сверяет новое и изменённое одним запросом, отправляет, правит, удаляет,
ставит реакции, загружает файлы. Окно продлевает ключ раз в 10 минут.

## Ключ доступа

Ключ подписан и живёт 30 минут; передаётся заголовком `Authorization: Bearer <ключ>`.
Выдаётся только собеседнику, записанному в беседе и не отключённому. Секрет подписи
создаётся в базе при первой выдаче; его смена гасит все выданные ключи. Без ключа,
с чужим или просроченным ключом сервис отвечает 401 с причиной.

## Адреса

Корень — `webchat`, беседа — в пути: `…/api/webchat/{беседа}/…`.

| Путь | Метод | Что делает |
|---|---|---|
| `/messages` | GET | порция сообщений (`?before=<номер>` — предыдущая), признак «можно писать» |
| `/messages` | POST | отправить сообщение |
| `/messages/{сообщение}` | PUT, DELETE | изменить, удалить |
| `/messages/{сообщение}/reaction` | POST | поставить или снять реакцию |
| `/messages/{сообщение}/files/{номер}` | GET | файл (`?preview=1` — превью изображения) |
| `/uploads` | POST | загрузить файл до отправки (`?name=<имя>`) |
| `/sync` | POST | новое, изменённое и удалённое с последней сверки |
| `/avatars/{собеседник}` | GET | аватар участника или автора сообщения беседы |
| `/avatar` | GET | аватар беседы |
| `/members` | GET | участники: имя, состояние, «в сети» (без администраторов и отключённых) |
| `/ping` | GET | проверка ключа |

Права на каждое действие считает сервер по состоянию собеседника в беседе и отдаёт
в данных сообщения (`МожноОтветить`, `МожноИзменить`, `МожноУдалить`, `МожноРеагировать`):
виджет показывает только разрешённые кнопки, а сервер повторно проверяет каждое действие.

Исключения обработчиков записываются в журнал событий событием `ОшибкаВебЧата`,
клиенту уходит 500 с причиной «подробности — в журнале событий».
